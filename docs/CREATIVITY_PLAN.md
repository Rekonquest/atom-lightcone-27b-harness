# Creative primitive split and falsifiers

This is a build contract, not evidence of achieved creativity. The source is
`atom_creativity_engine.py` at SHA-256
`6cc2a04d5a988d68b6f23530268e3723c96879fe5aa26de547f655615fb17e39`.
The coupled consumer is `atom_integrated_creativity_engine.py` at SHA-256
`22af0de70e60cd79a379c87c1f6b8e3cb7b302d8eb6f773d53bf8e032b2f0901`.

The approved one-way chain is causal primitives -> creative primitives ->
reasoning engine -> fixed orchestrator. Each crate must stay within 500
normally formatted physical lines, including tests and its manifest. Atom
crates use no external dependencies.

| Primitive | Its own mechanism | Required evidence |
| --- | --- | --- |
| Generation and selection | Enumerate distinct candidate combinations before ranking. | Generated IDs and selected frontier retain traceable origins. |
| Conceptual blending | Combine concepts from distinct spaces. | Every contributing space and concept is recorded. |
| Constraint-based creativity | Reject forbidden pairs before selection. | No hard-invalid candidate appears in admitted frontier. |
| Novelty and value balance | Measure difference from memory separately from coverage and usefulness. | Neither novelty alone nor utility alone determines selection. |
| Problem framing | Remap requirements through declared aliases. | Every reframe retains the original requirement ID. |
| Tension transformation | Add a declared bridge when both poles are present. | Neither pole disappears and an undeclared bridge is rejected. |
| Memory recombination | Offer prior concepts as candidate material. | Memory changes candidates but never grants factual or causal truth. |

Candidate order: validate typed brief and concepts; focus concepts using the
reasoning result; apply declared frames; generate bounded combinations and
cross-space blends; transform stated tensions; reject hard-invalid options;
measure novelty and value independently; retain a diverse nondominated
frontier. The reasoning engine, not the orchestrator, consumes the resulting
proposals together with separate probability and prediction assessments.

Measure coverage, valid frontier count, novelty/value diversity, provenance,
candidate stability, abstention on impossible briefs, and zero factual
promotions. Keep the original integrated benchmark as a historical reference,
not a parity receipt for this port. Compare the intact composition against
each omitted primitive, a reordered hard-constraint stage, and a simple
single-concept rule baseline on frozen cases. If candidate changes do not
track the intended primitive interventions, the mechanism claim fails.
